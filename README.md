One haiku for make.fun's "Seventeen Syllables of Debugging" bounty — three lines in the 5-7-5 syllable shape about debugging, at most 200 characters:

> Breakpoint set at three
> cursor blinks, the log scrolls on
> it was a typo

`main.py` checks the 5-7-5 syllable shape, prints the haiku, and writes it to `/output/entry.txt`. The three lines count 5, 7 and 5 syllables (72 characters in total, within the 200-character limit).

## Run it

```sh
python3 main.py
```
